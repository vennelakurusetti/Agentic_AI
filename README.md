# Agentic_AI

This repository contains a collection of mini-projects focused on agentic AI, prompt engineering, and interactive AI applications.

## Projects

- AIQuizGenerator: A small app for generating quizzes with AI assistance.
- multimodel-app: A multi-model application demo that explores model interactions.
- prompt_doctor: A prompt evaluation and improvement project.
- Content_Engine_Pro: A content generation workflow with text, image, and video support.
- college_faq_chatbot: A chatbot project built for answering college-related frequently asked questions.
- AI_Content_Engine: A project focused on generating AI-driven content using multiple modules.
- prompt_pipeline: A prompt-based processing pipeline for experimenting with LLM workflows.

## Purpose

These projects are intended for learning, experimentation, and demonstrating practical use cases of AI agents, prompt-driven workflows, and interactive AI applications.

## Getting Started

1. Clone the repository.
2. Open any project folder and follow its local README or setup instructions.
3. Install dependencies using the relevant requirements file if present.

## Technologies

- Python
- Streamlit / web-based interfaces
- Prompt engineering and AI application experiments
- LLM workflows and agent-based systems
