# 🤖 Agentic AI Projects

A collection of AI-powered applications built to explore **Agentic AI**, **Retrieval-Augmented Generation (RAG)**, **Prompt Engineering**, **LangGraph**, **CrewAI**, and modern LLM workflows.

These projects demonstrate autonomous agents, intelligent chatbots, multi-agent systems, and AI-powered content generation using Python and Streamlit.

---

## 🚀 Projects

| Project | Description | Tech Stack |
|---------|-------------|------------|
| 🤖 AI Recruitment Engine | Autonomous recruitment agent that parses resumes, scores candidates, ranks applicants, and supports interview scheduling with guardrails. | LangGraph, Streamlit, OpenRouter, Pydantic |
| 👥 Multi-Agent Recruitment AI | Multi-agent recruitment workflow with specialized AI agents collaborating on candidate evaluation. | CrewAI, Python, LLMs |
| 🎓 College FAQ Chatbot | RAG-based chatbot for answering college-related queries using semantic search and vector databases. | LangChain, Streamlit, FAISS/ChromaDB |
| 📝 AI Content Engine | AI-powered content generation platform for creating structured content using LLM workflows. | Python, Streamlit |
| 🎨 Content Engine Pro | Advanced multi-modal content generation supporting text, images, and video workflows. | Python, LLM APIs |
| 🩺 Prompt Doctor | AI assistant that analyzes and improves prompts for better LLM responses. | Python, Prompt Engineering |
| 🔄 Prompt Pipeline | Modular prompt orchestration framework for building multi-stage AI workflows. | Python |
| ❓ AI Quiz Generator | Automatically generates quizzes from user topics and difficulty levels. | Python, Streamlit |
| 🤝 Multi-Model App | Compare and evaluate responses from multiple LLMs within a single interface. | Python, Streamlit |
